# Лабораторная работа № 1 (КПиЯП)

**Дисциплина:** «Конструирование программ и языки программирования»  
**Тема:** «Разработка, отладка и испытание разветвляющихся и циклических алгоритмов и программ»  
**Вариант:** 11 (задания 2, 3, 4, 6, 7, 8), 1 (задание 5)  
**Среда:** .NET 9, C#, консольные приложения

## Цель работы

Познакомиться с операторами ветвления и циклов и научиться использовать их
в программах на C# в среде Visual Studio.

## Структура решения

```
KPiYaP.LR1/
├── KPiYaP.LR1.sln        # решение Visual Studio
├── Task01/               # диалог с пользователем: сумма чисел
├── Task02/               # сумма цифр трёхзначного числа
├── Task03/               # значение функции y = x / ((x - 15)(x + 2))
├── Task04/               # точка внутри / на границе / вне области
├── Task05/               # название месяца по номеру (switch)
├── Task06/               # числа из [A; B], оканчивающиеся на нечётную цифру
├── Task07/               # матрица 6 × 6 с диагональю
└── Task08/               # таблица значений кусочно-заданной функции
```

Каждое задание — отдельный консольный проект, поэтому запускать их можно
независимо друг от друга.

## Задания

| № | Условие | Ключевой приём |
|---|---------|----------------|
| 1 | Запросить числа с клавиатуры и вывести их сумму | `Console.ReadLine`, `double.Parse`/`TryParse`, интерполяция строк |
| 2 | Заканчивается ли сумма цифр трёхзначного числа на 2 | целочисленное деление `/` и остаток `%`, тернарный оператор |
| 3 | Вычислить `y = x / ((x − 15)(x + 2))` | проверка деления на ноль (`if`/`else`) |
| 4 | Определить положение точки в заштрихованных областях | сложные логические условия `&&`, `\|\|` |
| 5 | Вывести название месяца по его номеру | `switch`-выражение |
| 6 | Вывести числа из [A; B], оканчивающиеся на нечётную цифру | цикл `for`, `Math.Abs` |
| 7 | Вывести матрицу 6 × 6 с номером строки на диагонали | вложенные циклы, условие `row == column` |
| 8 | Построить таблицу значений кусочно-заданной функции | цикл `for` с вещественным счётчиком, `Math.Sqrt` |

### Задание 8. Функция (вариант 11)

```
        ⎧ 1 / (x² + 2x − 15),  если −6 < x < 6;
   y =  ⎨ √(x + 8),           если x < −7;
        ⎩ x³,                  если x ≥ 10.
```

В точках `x = 3` и `x = −5` знаменатель обращается в ноль, а на промежутках
`[−7; −6]` и `[6; 10)` функция не определена — в таблице выводится «не опр.».

## Сборка и запуск

```bash
# сборка всего решения
dotnet build KPiYaP.LR1.sln

# запуск отдельного задания
dotnet run --project Task02
```

Либо открыть `KPiYaP.LR1.sln` в Visual Studio, выбрать нужный проект
(«ПКМ → Назначить запускаемым проектом») и нажать **F5**.

## Что доработано по сравнению с черновой версией

- добавлена проверка корректности ввода (`TryParse` вместо `Parse`, повторный запрос при ошибке);
- в задании 1 исправлен вывод суммы второй пары чисел (печаталось `d + c` вместо значения суммы);
- в задании 4 условия «внутри» и «на границе» вынесены в отдельные методы, чтобы не дублировать логику;
- в задании 5 вместо длинной цепочки `case` использовано `switch`-выражение;
- в задании 6 последняя цифра вычисляется явно (`Math.Abs(i % 10)`), что корректно и для отрицательных чисел;
- в задании 8 аргументы и шаг считываются как `double` (в черновике были `int`), добавлена защита от нулевого шага и от деления на ноль в точках `x = 3` и `x = −5`.
