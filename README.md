# Путь спортсмена 🏋️

Курсовой проект по дисциплине **«Технологии разработки программного обеспечения»**  
Группа **ПЗТ-45**, курс 2–3.

**Автор:** kevradenis606-ai

---

## О проекте

«Путь спортсмена» — 2D-игра на **C++** с графической библиотекой **Raylib**, выполненная в стиле Pixel Art. Игрок помогает главному герою Ивану пройти путь от новичка до чемпиона: собирает спортивный инвентарь, выбирает полезную еду, распределяет продукты по БЖУ, налаживает режим сна, позирует на сцене и участвует в армрестлинге.

Игра в интерактивной форме обучает основам здорового образа жизни, спортивного питания и тренировок.

## Возможности

- 🏋️ 5 мини-игр: гантели, выбор еды, БЖУ, режим сна, позирование;
- 🤼 дополнительный режим «Армрестлинг» с 4 уровнями сложности;
- 🗺️ карта прохождения и последовательное открытие уровней;
- 🌐 три языка интерфейса: русский, английский, белорусский;
- 🎵 фоновая музыка и графика в стиле Pixel Art;
- 💾 встроенная справочная система (CHM).

## Сборка и запуск

1. Установите **Visual Studio 2022** с рабочей нагрузкой «Разработка классических приложений на C++».
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/kevradenis606-ai/kursovoy-put-sportsmena.git
   ```
3. Откройте файл `курсовой проект(путь спортсмена).sln`.
4. Восстановите NuGet-пакеты: **ПКМ по решению → Restore NuGet Packages**.
5. Выберите конфигурацию **x64 / Debug** и нажмите **F5**.

> Для запуска собранного `.exe` рядом с ним должен находиться `raylib.dll`
> из папки `packages/raylib.5.5.0/build/native/lib/x64/`.
